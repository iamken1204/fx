# 人話

人話，就是讀者看不出是機器寫的中文。台灣人寫文章有幾個習慣：動詞兩個字、東西直接點名、偶爾來一個成語或文言虛詞、語氣副詞多、句子長短不一。AI 中文每一樣都剛好相反，修改就盯住這幾樣。開場白、條列牆、三連發這些不分語言的 AI 腔，交給 unslop；這裡只處理中文特有的。

用詞的原則是「換掉所有台灣人不會講的詞」，不是「換掉清單上的詞」。本文裡的每張表都是例子，用來建立手感；表外的詞照同一個判準處理。

## 動詞兩個字

台灣人的動詞習慣兩個字。單字動詞一律補滿，兩條路：加上補語（拆→拆開、扛→扛起、擋→擋下、補→補齊、卡→卡住、抽→抽出），或換成同義複詞（拆→拆解、扛→承擔、撐→支撐、抓→掌握、砍→刪除、收→收斂、疊→堆疊、綁→綁定、套→套用、接→串接）。是、有、做、用、寫、看、說這類基本動詞本來就一個字，照舊。

「這個元件太大，要拆；流量由後端扛。」→「這個元件太大，要拆開；流量交給後端承擔。」

## 主詞點名

「伺服器一側負責驗證，客戶端那端則處理渲染。」一側、一邊、這端、那端、另一端、前者、後者、此處、該處——這些代稱是為了把兩件事擠進一個長句。每看必修：名詞寫出來，句子切成兩句。「伺服器負責驗證。客戶端負責渲染。」中文不忌重複，同一個名詞再寫一次，比任何代稱都清楚。「而…則…」「一方面…另一方面…」是同一種句型，同樣處理。

## 成語與文白夾雜

成語和文言虛詞是最省力的人味。

- 成語放在下判斷的位置，一篇一兩個就夠：治標不治本、捨本逐末、畫蛇添足、殺雞用牛刀、換湯不換藥、隔靴搔癢、因小失大、一勞永逸、牽一髮動全身。俗語同理：先求有再求好、沒魚蝦也好、羊毛出在羊身上。
- 文言虛詞夾在白話裡：恐、宜、尚、皆、亦、即可、方能、未必、以免、以利、實屬、所幸、不外乎、無非、反之、再者、此舉、為佳。「此法恐有副作用，宜先在測試機驗證；若無意外，下週即可上線。」

## 語氣

語氣副詞是人味的另一個來源：倒是、反而、畢竟、反正、難怪、頂多、至少、乾脆、索性、不妨、難免、未免、總算、偏偏、居然、其實、說穿了、老實說。「這招倒是可行，頂多慢一點。」輕鬆的場合，台灣口語直接用：卡關、踩雷、搞定、沒差、還好、蠻、超。

句子長短錯落，一段裡要有一句五個字以內的短句。長句是流水句：逗號一路順下去，主詞能省略就省略，句子的骨架是語序，而不是「在…的情況下」「透過…的方式」這種框架。

## 用詞

判準只有一個：台灣的工程師跟同事講話、台灣出版社的技術書、教育部辭典，會不會這樣用。三者都不會，就換掉。下面兩張表是最常踩到的例子，不是完整清單；表裡沒有的詞，照樣用這個判準處理。

中國用語常見的幾類，逐句讀的時候每一類都要想到：

- 技術詞對譯不同：軟件、服務器、內存、緩存、字段、對象、接口、數據庫……
- 日常詞不同：視頻、信息、質量、水平、反饋、優化、打造、立馬、靠譜……生活用品也是：充電寶、U盤、短信、郵箱、網民、橙汁、易拉罐（台灣講行動電源、隨身碟、簡訊、信箱、網友、柳橙汁、易開罐）
- 譯名不同：新西蘭、悉尼、老撾、朝鮮、傅里葉、東盟（台灣寫紐西蘭、雪梨、寮國、北韓、傅立葉、東協）
- 政治立場帶進來的詞：內地、祖國、大陸同胞、英聯邦。台灣人寫中國、中國人、大英國協
- 商業與管理黑話：賦能、落地、抓手、閉環、痛點、對標、復盤、沉澱、拉通、顆粒度
- 語法習慣：「有…的存在」、「…的話」連用、「挺」、「啥」、「咋」、「整」當萬用動詞
- 字形與標點：着／著、裏／裡、爲／為、“”／「」

同一個詞在不同語境可能是台灣用法，要看上下文再決定：質量（物理量）、水平（方向）、支持（支持某人的立場）、程序（法律程序）、反饋（電路學的回授）都不算中國用語，照留。反過來，有些詞台灣本來就有，只是在 IT 語境另有說法：地址（郵寄地址照舊，記憶體位址才是位址）、場景（戲劇場景照舊，使用情境才是情境）、日誌（日記照舊，程式記錄才是記錄檔）、菜單（餐廳照舊，軟體才是選單）、證書（畢業證書照舊，SSL 才是憑證）、循環（循環經濟照舊，程式才是迴圈）、導入（公司導入系統照舊，資料才是匯入）。

歐化句照余光中的方子修改：

| 看到 | 改成 |
|---|---|
| 進行討論、作出決定、加以處理 | 討論、決定、處理 |
| 重要性、必要性、…化 | 重要、必要、還原成動詞 |
| 一個、們、很好地／成功地 | 刪掉 |
| 被儲存、被呼叫 | 主動句 |
| 作為開發者 | 身為開發者 |
| 透過…的方式、在…方面、對於…來說 | 刪掉框架，直接說 |
| 這意味著、旨在、擁有、存在問題 | 也就是說、是為了、有、有問題 |
| 值得注意的是、需要注意的是 | 刪掉，直接講那件事 |
| 總的來說、綜上所述、首先／其次／最後 | 停筆；刪掉序號 |
| 不僅…還…、無論是…還是… | 只講一個 |
| …，從而／進而／這使得… | 句號，另起一句 |
| …，以確保／從而確保 X | 句子在逗號處結束 |

中國用語換成台灣寫法：默認→預設、用戶→使用者、通過…→透過…、實現→實作、支持→支援、獲取→取得、創建→建立、返回→回傳、調用→呼叫、配置→設定、反饋→回饋、質量→品質、項目→專案、視頻→影片、信息→資訊、數據庫→資料庫、字段→欄位、變量→變數、對象→物件、函數→函式、接口→介面、緩存→快取、代碼→程式碼、程序→程式、算法→演算法、文檔→文件、軟件→軟體、網絡→網路、服務器→伺服器、內存→記憶體、智能→智慧、打印→列印、屏幕→螢幕。

## 檢查

逐句檢查，五項全部通過才算完：

1. **動詞** — 單字動詞只剩是、有、做、用、寫、看、說這類基本動詞，其他都兩個字。
2. **代稱** — 一側、一邊、那端、前者後者、此處該處，零個；每個動作的主詞都點了名。
3. **人味** — 三百字以上的文章，成語或俗語、文言虛詞、語氣副詞各至少一處。
4. **用詞** — 逐句唸，每個詞都問一次「台灣人會這樣講嗎」。表裡的詞只是提醒，不是範圍。最後可以用 grep 或字典式的 linter 對表掃一遍當保險，但掃描不能取代逐句閱讀；只做掃描就交稿，等於沒做這一項。
5. **唸出來** — 唸一遍，不像台灣人跟同事講話的那句，改成嘴巴會講的說法。
